# Registros e Arquivos em C

Atividades da disciplina de Algoritmos e Pensamento Computacional.

- `atividade2.c` - Funcionário com malloc, backup com memcpy e gravação em backup_rh.bin
- `atividade3.c` - Atualização de saldo em clientes.bin usando rb+ e fseek
- `atividade4.c` - Cadastro de N professores gravado em folha.dat com um único fwrite
- `atividade5.c` - Registro de votos com realloc, struct aninhada e leitura com fseek/ftell

## Como compilar

```
gcc atividade2.c -o atividade2
./atividade2
```
